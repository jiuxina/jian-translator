## 可复用测试入口

在仓库目录运行：

```powershell
node tests/serve-audit-browser.mjs 8898
```

然后在 Codex 内置浏览器分别打开：

- 应用：`http://127.0.0.1:8898/?debug=1`
- 合成响应控制台：`http://127.0.0.1:8898/__audit/controls`

服务仅绑定回环地址，只提供仓库 `web/` 和指定测试资源；生产 HTML、构建配置及发布资源不引用测试脚本。控制台以同源 BroadcastChannel 设置响应场景和释放挂起任务。

测试预载器替换翻译响应、更新响应、剪贴板和文档选择。支持正常完成、令牌截断、服务错误、缺少结束原因、CRLF、EOF 末帧、空正文、文件读取延迟、图片剪贴板延迟与同 ID 划词投递。输入必须使用合成数据；不需要也不应读取真实剪贴板、上传真实文件或调用翻译服务。访问 `/__audit/report` 将本次服务进程的事件保存到上述 `.build` 路径。

## 边界

本轮是针对修复行为的内置浏览器集成验收，没有重跑已经完成的离线汇总集合，也不能替代原有完整 CDP 动画/性能套件。没有验证 WebView2/Tauri 原生窗口、MSI 实际升级卸载、macOS 前台应用/系统快捷键、Android 系统文件选择器、进程重建、TalkBack、设备相机或平台编译。上述平台项目仍保持“未执行”，不计为通过。

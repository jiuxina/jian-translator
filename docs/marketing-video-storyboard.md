# 「笺」宣传片分镜与 AE 制作计划

## 创意总纲

**片名暂定：**《从选中，到读懂》

**核心生活瞬间：** 用户在电脑上读到一句陌生外语，停下来选中它；「笺」把译文安静地放到眼前，阅读继续。

**成片规格：** 16:9、1080p、30 fps，目标时长 48–52 秒，最终不超过 3 分钟。旁白使用指定的 Uzuki 声音，中文字幕烧录并另存 `.srt`。

**视觉原则：**

- 单一主体：整个镜头链只围绕一块「笺」翻译界面展开；手机录屏不作为并列卖点出现，避免多主体抢夺注意力。
- 背景留白：使用浅灰到暖白的极浅渐变；片头和片尾可用纯黑，保持大面积留白。
- 材质优先：录屏嵌入一块银灰色显示面板，边缘只留细腻的金属轮廓光与一条低亮度反射扫光。译文浮窗原有的高反差壁纸以白色阅读面板重新整理；原文、译文、语言方向和复制入口保留可读，不照搬背景插画。
- 运镜克制：使用缓慢推近和横移；镜头之间用柔和的金属边缘扫过衔接，禁止硬切、闪白、旋转、粒子和故障特效。
- 文字克制：AE 文字只承担情绪和节奏，不重复界面中的功能标签；入场使用遮罩、透明度、字距和 6–10 px 的微位移，镜头稳定后再出现。

## 旁白与字幕节拍

旁白只说生活化动作，不口播参数和功能清单：

1. **0:00–0:04** 有时，不懂的只是一句。
2. **0:04–0:10** 你正在读一段外文。
3. **0:10–0:16** 选中它。
4. **0:16–0:22** 译文，安静地出现在眼前。
5. **0:22–0:30** 原文与译文，同屏呈现。
6. **0:30–0:37** 只需要一瞬间。
7. **0:37–0:44** 看懂之后，继续读下去。
8. **0:44–0:52** 从选中，到读懂。

字幕一律使用简体中文，放在画面安全区下方；单句最多两行，每行不超过 14 个汉字。字幕出现时间比人声晚 2–3 帧，消失时间比人声早 2–3 帧，避免字幕抢在画面动作前解释结果。

## AE 执行规范

- **素材处理：** 录屏按原比例像素裁切，先做轻微去噪与锐度恢复，再嵌入单一面板。不得用拉伸、非等比缩放或重绘 UI 字体。
- **面板材质：** 银灰渐变填充、4–6 px 金属边、低透明度柔和倒影；倒影只在边框移动，不能扫过文字内容。
- **文字动画：** 使用矩形遮罩 + 透明度 + 6–10 px 位移 + 缓入缓出。字距从 20% 回落到设计值，持续 8–12 帧；字幕采用简洁的低对比浅底，保持在界面以外的底部安全区。
- **焦点提示：** 选区 focus ring 只出现一次，线宽 1 px，持续不超过 18 帧，随后自然淡出，避免变成第二个主体。
- **转场：** 面板与柔和的金属细线由左向右移动，引出下一镜；不用硬切、闪白、旋转镜头或花哨预设。
- **混音：** 旁白峰值约 -3 dB，背景音乐比旁白低 8–10 dB；鼠标、确认、纸页声只做动作提示，不制造“科技感”噪声。

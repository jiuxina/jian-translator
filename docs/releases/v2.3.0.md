# 笺 v2.3.0 · 玻璃材质与交互优化

本次更新统一 Windows、macOS、Android 和网页的版本显示，优化玻璃材质与交互响应。
Android 使用 versionName 2.3.0 / versionCode 6。

## 本次更新

- 模型选择器（含 2B/9B）与设置分类滑块始终呈现液态玻璃，静止、按住、拖动和松开时材质一致。
- Tab 栏保留透明玻璃外观，按住时不再切换折射强度或底色；按钮与下拉入口同样保持固定材质。
- 内容卡片、设置、菜单、下拉弹层和悬浮窗内容使用静态磨砂，将光学处理集中到交互控件。
- Android 连续调整设置与拖动选择按帧合并更新；支持的 WebView 在后台生成光学贴图。
- 打开和刷新语言下拉时不自动聚焦搜索框，主动点击搜索框后仍可搜索。
- 手机底栏提供独立齿轮入口，保留拖动切换、安全区避让与键盘操作。

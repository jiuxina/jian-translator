# 笺 v2.2.0 · 首个公开预览版

这是笺的首个 Release 候选，提供 Windows 和 Android 安装包。
本次建议标记为 **Pre-release**，先收集目标设备的兼容性与性能反馈。
macOS 已加入源码适配和构建流程，本次没有经过 Mac 实机验证的 DMG/ZIP。

## 主要功能

- 文本、图片、音节控制和长文翻译，共用 bilibili Index-Translate 官方公开 API。
- Windows 托盘、快捷键唤起、划词悬浮窗与全文复制。
- 浅深主题、配色、壁纸、字重和字体颜色；桌面端可选择系统实际可用字体。
- 卡片、Tab/模型切换滑块、按钮分别使用对应的液态玻璃预设，只提供各演示公开的滑条。
- 模式和模型支持按住拖动切换；设置导航使用连续滑块与内容过渡。
- 设置页提供自动检查更新、手动检查和发布页入口。
- 手机端设置入口位于底栏，优化安全区、点击高亮与文本滚动条。
- 关于页展示版本和开源仓库；主按钮使用“翻译”，长文导出使用“下载”。

## 下载选择

| 附件 | 用途 |
| --- | --- |
| `Jian-2.2.0-windows-x64.msi` | Windows x64 安装版。 |
| `Jian-2.2.0-windows-x64.exe` | Windows x64 独立程序；运行时仍需要 Microsoft Edge WebView2。 |
| `Jian-2.2.0-android.apk` | Android 7.0（API 24）及以上，versionCode 5。 |
| `SHA256SUMS.txt` | 上述三个附件的 SHA-256 校验值。 |

Windows EXE/MSI 未进行 Authenticode 签名。安装前请核对附件来源和 SHA-256；
如果系统拦截，请先确认发布者与文件来源，不建议关闭系统安全保护。
本项目是非官方客户端，与哔哩哔哩无隶属关系。

## 本次验证与已知限制

- Windows EXE/MSI 和 Android Release 已构建；APK 内六项前端资源与源码一致。
- 首发准备阶段的唯一一次完整浏览器回归为 **140/142**，Rust 为 **93/93**。
  两项失败已定位为测试的背景层读取与跨场景保存延迟遗留，修正后只做定向验证，
  两项均通过，未重跑完整套件。更早实现阶段的 97/107 属于另一轮历史记录。
- Windows EXE 文件属性和 MSI 产品版本均已统一为 **2.2.0**。
- 完整液态玻璃有明显合成成本，本机定向样本多数约 95ms/帧，不能承诺 60fps。
- Windows 多 DPI、原生圆角阴影及系统剪贴板，Android System WebView 最终绘制与性能，
  仍需目标设备验收；桥接替身通过不等于原生验收通过。
- macOS 本次仅提供源码适配说明，没有 Mac 安装包或实机通过声明。
- 自动更新仅检查正式 GitHub Releases；本次预发布不会进入应用的“最新正式版”更新通道。
  可以直接访问仓库 Releases 获取此预览包。

发布资产的实际字节数、版本属性与 SHA-256 以同目录的 `release-manifest.json`
及 `SHA256SUMS.txt` 为准。发布前仍须完成源码检查点与第三方许可核对。

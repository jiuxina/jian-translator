# 笺 v2.4.4 · 阅读体验与统一字体粗细

本版本改善 Windows、macOS、Android 与网页版的文字阅读体验，并统一字体粗细设置。
Android 使用 versionName `2.4.4` / versionCode 11。

## 原文与译文更易阅读

- 主界面正文基准字号调整为桌面 16px、窄屏 15.5px，行高统一为 1.8 倍；继续支持已有字号缩放、字体和自定义文字颜色。
- 提升原文、译文标题、占位提示、字数统计及模式说明的文字对比度，保留浅色与深色主题。
- Windows 与 macOS 划词浮窗正文基准字号调整为 15px，适度放大标题、等待提示和底栏文字；保留窗口尺寸与正文滚动。

## 一个选项统一调整字体粗细

- 在“设置 → 阅读与布局 → 界面字体粗细”中，统一调整导航、按钮、设置、原文、译文及划词浮窗的文字。
- 提供 300–700 五档字重，默认 400；实时生效并自动保存，已有字重偏好继续沿用。
- “恢复本组默认”统一恢复常规字重；调整字重后重新测量下拉标签、对齐导航与模型滑块，避免文字裁切和选中指示错位。

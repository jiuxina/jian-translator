# 笺 v2.4.5 · 桌面剪贴板翻译与重复输出修复

本版本为 Windows 与 macOS 增加统一的剪贴板翻译快捷键，可直接翻译复制的文字或图片，
并修复翻译过程中可能持续循环输出同一词句的问题。
Android 使用 versionName `2.4.5` / versionCode 12。

## 剪贴板内容一键翻译

- Windows 默认 `Ctrl+Alt+V`，macOS 默认 `Cmd+Alt+V`；可在“设置 → 电脑功能”查看并修改。
- 复制文字或截图后按快捷键，笺会打开主窗口、填入内容并自动开始翻译。
- 剪贴板同时包含文字和图片时优先翻译图片；图片复用原有缩放、预览和视觉翻译流程。
- 读取和图片解码期间继续编辑、清空或替换内容时，较早的异步结果不会覆盖新输入。
- 仅在用户触发快捷键时读取剪贴板；启动和空闲预热不会读取剪贴板内容。

## 翻译稳定性

- 检测到译文持续异常重复时，自动停止当前请求并提示重试，避免同一词句不断输出。
- 文字、图片、音节、文档翻译及桌面划词浮窗共用此保护；异常结果不会作为成功译文保存。
- 检查会参考原文中的重复情况，并设置重复次数和长度门槛，减少对短强调和正常重复内容的误判。
- 文档分块翻译遇到异常重复时，保留此前已完成的分块，异常分块不作为完成结果保存。

# 笺 v2.4.1 · 自启动目标、窗口边缘与设置动画修复

本版本修复 Windows 多版本共存时自启动目标不明确、无边框窗口四周白边，以及设置页关闭后短暂闪现的问题。
Android 使用 versionName `2.4.1` / versionCode `8`。

## 本次更新

- Windows 自启动读取系统登记的完整 exe 路径，显示目标是否存在以及是否属于当前版本。
- “设为当前版本”单独切换启动目标；普通设置保存不会改写 Windows 启动项。
- 访问注册表失败、目标文件移动或注册值损坏时显示可修复状态，不会误报为已关闭。
- 新安装默认关闭开机自启动和启动后最小化到托盘；用户保存过的显式设置继续生效。
- 同标识版本仍保持单实例；切换到其他版本前先退出当前运行版本。
- 修复 Windows 无边框窗口四周由原生阴影非客户区造成的白边，保留最大化工作区和圆角裁剪。
- 修复设置页关闭后透明状态恢复导致的闪现，覆盖快速重开、减少动态效果和兼容 WebView 回退路径。
- 补充 Windows 注册表、窗口边缘、设置动画、补丁器和跨平台版本一致性回归测试。

# 笺 v2.4.3 · 主界面性能与连贯体验优化

本版本优化 Windows、macOS、Android 与网页版共用的翻译主界面，重点改善设置分类、模式切换和下拉搜索的连贯性。
Android 使用 versionName `2.4.3` / versionCode 10。

## 设置切换更连贯

- 切换分类时保留当前页面，目标页在相同视口内隐形准备玻璃效果与贴图，就绪后再连续交接，减少等待期间的留白。
- 各分类保留独立滚动位置；快速改选、反向切换或窗口尺寸变化时，仅提交最新有效选择。
- 交接中关闭设置会保持当前画面组合随面板退出；重新打开时清理冻结的位移、透明度和层级，避免残留状态影响布局。
- 保留原有玻璃材质、缓动、位移和时长；减少动态效果时仍先完成玻璃准备，再即时切换。

## 模式切换与操作按钮

- 复用卡片矩形和当前视觉样式快照，集中读取动画所需几何，减少重复布局测量。
- 相同状态的空闲操作栏跳过无用读数，减少动态效果时跳过不必要的动画采样。
- 实际操作按钮仅在移动路径不会与“取消”等控件重叠、且系统支持时连续移动；任务开始、完成或取消时及时收束动画。
- 各模式继续使用原按钮、状态和点击行为，翻译接口与偏好结构保持不变。

## 下拉搜索更轻量

- 语言和字体下拉缓存规范化搜索标签；筛选条件、选项和当前值均未变化时，复用现有列表。
- 列表更新集中完成，点击处理采用事件委托，减少反复创建节点和监听器。
- 保留选项排序、分组、禁用状态、键盘导航与焦点行为；搜索逐次输入即时生效，不增加延迟。
- 打开语言下拉不会主动唤起手机输入法；临时键盘高亮退出后，重新打开回到当前选中项。

## 开机自启动：已知问题与解决办法

Windows 的开机自启动指向系统登记的那个程序文件。安装或解压新版本后，登记路径不会自动跟随，
可能出现"开关是开着的，开机启动的却是旧版本"。

可靠的做法（不需要修改任何文件）：

1. 退出所有正在运行的笺，包括托盘里的实例。
2. 只启动你希望开机自启的那个版本。
3. 进入设置，把"开机自启"先关闭、再打开一次。

完成后，开机启动的就是当前这一版。

注意：

- 不要在旧版本仍在运行时打开新版本去切换——单实例机制会让新版本直接退出，设置仍由旧版本写入。
- 设置里的勾选只表示启动项存在，不代表它指向当前版本。
- 程序文件被移动或重命名后，按上面三步重新登记一次即可恢复。
- 如果开关行为异常（例如关闭后仍残留），同样先退出全部实例再重试，让界面状态与系统登记重新对齐。

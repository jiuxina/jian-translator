# 笺 v2.4.2 · 翻译可靠性与跨平台体验修复

本版本集中修复翻译任务相互干扰、流式结果不完整，以及划词、文件导入和图片粘贴中的异步问题。
Android 使用 versionName `2.4.2` / versionCode `9`。

## 翻译与长文

- 文本、音节和长文任务独立运行，切换模式不再阻塞其他模式；新增“取消”，保留已完整翻译的内容。
- 修复清空后旧译文重新出现，以及迟到的文件读取、剪贴板结果覆盖新编辑的问题。
- 流式响应截断、中断、服务错误或返回空正文时明确提示失败，避免把不完整结果当成完整译文。
- 完善 CRLF、多行流式事件和 EOF 末帧处理，增加连接与读流超时。
- 长文翻译固定开始时的语言、模型和分块设置；取消或区块失败时保留已完成区块，不把进度误标为完成。
- 复制与下载仅使用真实的完整结果，不再输出占位文案、错误文字或未完成预览。
- 主页面源语言支持全部语种；完善图片粘贴，透明图片转 JPEG 前先铺白底。

## 桌面与 Android

- Windows 划词增加请求去重，避免重复翻译和覆盖用户编辑；快捷键仅在按下时触发，释放不再执行第二遍。
- Windows 剪贴板读取增加内存边界检查；发布构建关闭临时诊断日志写入。
- Windows 安装器增加自启动路径迁移和卸载清理，仅管理本次安装拥有的目标，保留其他安装及便携版的启动项；全新安装仍默认关闭自启动。
- Android 补齐长文的系统文件打开与保存桥接，并增加相册、相机及文档结果在页面或活动重建后的恢复处理。
- Android 相机改善快门无障碍名称、单摄设备兼容和照片确认预览的 EXIF 方向处理。
- macOS 划词等待期间支持 Escape 取消；切换应用后，迟到的取词结果不会再无条件夺回焦点。
- 发布流程增加标签、版本清单和附件版本校验，并将离线验证作为构建与发布的前置条件。
